## About

**Board Games** is a frontend project focused on timeless strategy games and the culture around them. It brings together game discovery, rules, history, learning material, editorial content, and game-specific board interfaces in one responsive application.

## Features

- Browse a catalog of traditional strategy games
- Explore dedicated pages with rules, pieces, history, and game metadata
- Interact with game-specific board interfaces for selected games
- Follow structured learning paths grouped by game and difficulty
- Read journal-style essays, profiles, history, and analysis
- Switch between light and dark themes
- Use a responsive interface built from reusable UI primitives
- Maintain clear boundaries through a pragmatic feature-based architecture

## Getting started

### Requirements

- Node.js 20.9 or newer
- npm

### Installation

```bash
git clone https://github.com/denys-suhachenko/board-games.git
cd board-games
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Project status

This project is under active development. The current version focuses on the visual system, content structure, reusable components, game pages, and selected board interactions.

Some buttons and flows represent planned functionality and should not yet be treated as complete matchmaking, engine, account, or multiplayer features.
